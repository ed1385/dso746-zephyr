# DSO-746 — справочная страница прибора

Демонстрационный трёхрежимный прибор на **STM32F746G-DISCO**: осциллограф,
анализатор спектра и генератор сигналов на одном сенсорном экране 480×272 под
**Zephyr RTOS + LVGL 9**. Внешних деталей не требует — работает на том, что
есть на плате.

## Режимы работы

- **Осциллограф** — два канала, одновременная выборка, послесвечение,
  автоматические измерения, режим XY, курсоры, маркеры уровня запуска и нуля.
- **Анализатор спектра** — БПФ до 4096 точек, пять оконных функций, выбор
  полосы обзора, поиск пиков, водопад с тремя палитрами.
- **Генератор** — восемь форм сигнала, ввод частоты с клавиатуры, размах,
  смещение, скважность; включение выхода удержанием клавиши; отдельный
  калибратор/меандр.
- **Демонстрационный** и **боевой** — одна и та же логика и интерфейс,
  отличается только источник отсчётов: симулятор или АЦП. Переключение —
  синей кнопкой **B1 USER** на обратной стороне платы (вывод PI11). При
  включении прибор всегда стартует в демонстрационном режиме.

## Технические характеристики

### Осциллограф
| Параметр | Значение |
|---|---|
| Каналов | 2, одновременная выборка (ADC1/PA0, ADC3/PF10, общий запуск TIM2) |
| Разрядность АЦП | 12 бит |
| Макс. частота выборки | 1.80 MSa/s на канал (5.40 MSa/s одноканально — задел) |
| Макс. измеряемая частота | 360 кГц (при правиле выборка ≥ 5× сигнала) |
| Диапазон входа | 0…3.3 В (±5 В и ±50 В с щупом ×10 — с будущим трактом) |
| Цена деления | 20 мВ…2 В/дел, ряд 1-2-5 |
| Разрешение по напряжению | 0.81 мВ/LSB |
| Развёртка | 20 мкс…100 мс/дел, ряд 1-2-5, 13 ступеней |
| Длина записи на экран | 336…1344 отсчёта (min/max на столбец) |
| Предзапуск | 0…100 % записи (H.POSITION ±6 делений) |
| Отображение | послесвечение 0.1 с…∞, XY, сетка |

### Запуск
| Параметр | Значение |
|---|---|
| Тип | программный, по фронту, с гистерезисом и перевзводом |
| Источник | CH1, CH2 (EXT на PG6 — задел) |
| Фронт / режим | RISE/FALL/BOTH · AUTO/NORMAL/SINGLE |
| Гистерезис | 0…160 мВ шагами 8 мВ |
| Джиттер | ±1 отсчёт (0.56 мкс при 1.8 MSa/s) |

### Измерения
Vpp, Vmax, Vmin, Vavg, Vrms, частота, скважность.

### Анализатор спектра
| Параметр | Значение |
|---|---|
| Длина БПФ | 256…4096 точек |
| Окна | прямоугольное, Hann, Hamming, Blackman-Harris, flat-top |
| Полоса обзора | 8 / 32 / 128 / 900 кГц (частота выборки 16.4k…1.8M) |
| Разрешение по частоте | 4 Гц…440 Гц |
| Время БПФ 2048 | ≈ 0.3 мс (Cortex-M7 216 МГц с FPU) |
| Динамический диапазон | ≈ 70 дБ |
| Водопад | 84 строки, три палитры |

### Генератор (ШИМ-ЦАП на PB4)
| Параметр | Значение |
|---|---|
| Формы | синус, меандр, треугольник, пила ↑/↓, импульс, sinc, шум |
| Синус / треугольник / пила | 1 Гц…42 кГц |
| Меандр, импульс | до ≈1 МГц |
| Размах | 0.05…3.3 Vpp, шаг 50 мВ |
| Смещение | 0…3.3 В (амплитуда и смещение вместе всегда в 0…3.3 В) |
| Несущая ШИМ | 8 бит → 422 кГц, 10 бит → 105 кГц (выбор автоматический) |
| Ввод частоты | цифровая клавиатура, множитель Hz/kHz/MHz = применение |
| Калибратор / меандр | PH6 (D6), 2 Гц…2 МГц, скважность 0…100 % |

### Интерфейс и платформа
| Параметр | Значение |
|---|---|
| Экран | 4.3", 480×272, RGB565, двойная буферизация LTDC |
| Отрисовка луча | 20 кадров/с, карта интенсивности 8 бит на канал |
| Отклик на касание | опрос ввода каждые 10 мс |
| Ускорение графики | DMA2D (Chrom-ART) |

| Ресурсы | FLASH 44 % из 1 МБ, SRAM 47 % из 256 КБ, SDRAM 1.2 МБ из 8 |

## Управление

- **MODE** — переключение SCOPE → FFT → GEN.
- **RUN/STOP** — пуск и остановка; в генераторе — включение выхода удержанием.
- **Клавиши групп** — открывают панель параметров поверх луча.
- **Плитка параметра** — список открывает страницу вариантов (применяется
  касанием), шаговое значение сворачивает панель и правится клавишами − / +
  и перетаскиванием по лучу, частота открывает клавиатуру.
- **Перетаскивание по лучу** — смещение канала, уровень запуска, положение
  развёртки.
- Правило: **плюс всегда увеличивает то, что видно на экране**; недействующие
  в текущем состоянии клавиши и плитки скрыты.

Полная спецификация логики — в [UI-SPEC.md](UI-SPEC.md), архитектура от
железа до графики — в [architecture.md](architecture.md).

## Состояние проекта

Демонстрационный режим работает полностью. Боевой режим реализован, часть
функций проверена расчётом и хостовыми тестами. Не доведено: чередование АЦП
(развёртка ограничена 20 мкс/дел), измерение спектра ШИМ-ЦАП с фильтром,
аналоговый вход (пока 0…3.3 В).
